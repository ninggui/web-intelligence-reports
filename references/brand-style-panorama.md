# 品牌风格全景研究方法论（蔚来+小米案例验证）

> 2026-08-14 实战固化。两次完整验证：蔚来（官方62条+克杰陈+李安迪andylee）、小米（官方61条+雷军62条+拆解KOL）。

## 核心原则
1. **以品牌为主体，不按人分章**——组织维度是品牌调性/表达体系/文化内核/生态视角，不是"李斌/雷军/官方"分人罗列
2. 语言风格 vs 内容内涵分开学：官方学风格，KOL只学内涵（对品牌的深度解析）
3. 只用原版一手资料，禁截取媒体断章取义
4. 数据必须换算成用户价值；引用金句需标注来源人物/场合

## 三层表达体系模型（全景文档第二章）
| 层 | 承担者 | 语料来源 |
|----|--------|---------|
| 品牌层 | 官方账号 | 官方小红书/微博全量笔记（S3） |
| 人格层 | 创始人/CEO | 发布会实录+创始人社媒账号（S2） |
| 专业层 或 生态层 | 高管 或 粉丝生态 | 群访实录 / 粉丝玩梗文化（按品牌适配） |

**关键经验**：创始人社媒账号必须单独拉取——雷军小红书475万粉，远超官方号24.4万粉，是人格层核心语料。

## 全景文档结构
```
# XX品牌风格全景
## 第一章 品牌身份与调性（是什么/性格拟人/三观）
## 第二章 品牌表达体系（三层）
## 第三章 品牌文化内核（故事/关键词宇宙/仪式符号/危机范式）
## 第四章 品牌生态视角（KOL如何解读）
## 第五章 应用指南（场景→指纹速查/写作红线/金句库）
## 附录A：内容模板详版（6类以上）
```

## 语料获取要点（小红书 MCP）
- 定位官方号：多关键词（品牌名/车型/活动）按点赞排序，别被个人用户淹没
- 定位创始人号：直接搜"创始人名"（雷军475万粉/李斌等易命中）
- user_profile 需 xsec_token：从搜索结果提取（用完整userId，截短匹配失败）
- 批量拉正文：间隔≥3s，分批（每批≤20），失败重试；视频笔记desc常为空不影响风格提炼

## KOL生态解析（S5，用户确认后执行）
- 找深度精品KOL（资本面+产品面互补），如蔚来=克杰陈(资本/金融)+安迪(产品/长测)
- 列表给用户确认，每轮只确认纳入哪些；用户确认后标记"其他不纳入"
- 只提炼内涵观点+方法论，不学语言风格

## 用户偏好（重要）
- 用户说"修整为品牌为主体"→ 重构组织维度，不按人分章
- 用户一次性提多个有承上启下关系的需求 → 逐项确认进度，别丢任务
- 文档内容确认后**直接落地飞书**，不要再问"要不要同步"——用户会用"？"表达不满
- 研究完一个品牌后，用户可能要求：①固化流程为skill ②用新流程测试另一个品牌（本次=小米）
